# App Store Optimization (Play Store listing)

Paste into **Play Console → Main store listing**.

> Don’t put a competitor’s brand (“cricline”, “cricket guru”) in the listing. Rank for category terms users type.
> Lead with **scores + insights**, not odds/back-lay language (policy + brand trust).

---

## Title (max 30 chars)
```
Cricket Pulse: Live Scores
```

## Short description (max 80 chars)
```
Live cricket scores, match context & smart insights. Free, no login.
```

```

FORMATS & LEAGUES

Cricket Pulse keeps the score and the story one tap away — free, no sign-up.

Live cricket scores. Match insights. Scorecard. Free.
```

## Keyword research
Primary: `live cricket score`, `cricket scorecard`, `IPL live score`, `match centre`, `cricket pulse`.
Secondary: `T20 live`, `fixtures`, `points table`, `squads`, `match insights`.
Avoid leading with: `match odds`, `back/lay`, `session markets` as primary ASO terms.
